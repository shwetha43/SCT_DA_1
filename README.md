# Excel Sales Dashboard

## Project Overview
This project analyzes sales data using Microsoft Excel and presents key business insights through an interactive dashboard.

## Features
- Total Sales KPI
- Total Profit KPI
- Profit by Category Analysis
- Monthly Sales Trend
- Sales by Region
- Interactive Slicers
- Conditional Formatting

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Dataset
Sample Superstore-style sales dataset.



## Insights
- Technology generated the highest profit.
- Office Supplies generated the lowest profit.
- Sales showed growth over time.
- Regional performance can be filtered using slicers.
